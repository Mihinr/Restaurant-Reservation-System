Introduction
This assessment evaluates your ability to design, implement, and deploy production-ready software systems. We want to see how you architect solutions, make technical tradeoffs, implement clean code, and document your work for team collaboration.
You will build a restaurant reservation and table management system using modern software architecture principles. This assessment requires you to demonstrate advanced knowledge of system design, data modeling, API architecture, and deployment practices.

The Business Problem
A restaurant group operates multiple locations and needs a comprehensive digital system. Currently, they:
-	Manage reservations across multiple restaurant locations
-	Track table availability and capacity in real time
-	Handle walk-in customers and waitlist management
-	Need staff coordination for seating assignments
-	Want customer profiles with reservation history
-	Require reporting on occupancy rates and revenue
-	Need to handle peak hours with multiple concurrent bookings
The restaurant group wants a scalable system that can handle high traffic during peak hours and provide reliable service across multiple locations.

Your Task
Build a restaurant reservation system with a microservices architecture. The system must handle concurrent requests, maintain data consistency, and provide real-time updates across services.
Core scenarios:
-	Customers can search available tables by date, time, party size, and location
-	System must prevent double-booking and handle concurrent reservation attempts
-	Staff can manage table status and seating assignments in real time
 
-	System must handle reservation modifications and cancellations with appropriate business rules
